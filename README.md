# TSJ 独立站 + 内容管理后台

同一套代码、同一个 GitHub 仓库：`/` 是官网，`/admin/` 是后台。所有图片、文案、联系方式、接收邮箱都来自 `data/site.json`，后台改完提交后，官网刷新即生效（GitHub Pages 大约 30–60 秒重新发布）。

## 目录结构

```
index.html            官网首页（结构 + 表单 + 弹窗）
css/style.css         官网样式（含手机端适配）
js/countries.js       全球国家 / 地区 + 国际区号（209 项）
js/site.js            官网渲染逻辑、轮播、10 秒弹窗、线索提交
data/site.json        ★ 全站内容（后台编辑的就是这个文件）
assets/img/           站点图片（自托管，可替换）
admin/index.html      后台页面
admin/admin.js        后台逻辑（登录、表单生成、GitHub 发布、图片上传）
admin/admin.css       后台样式
```

## 一、部署到 GitHub Pages

1. 把本目录全部文件推到仓库 `XiaoCaoLSJ/TSJ` 的 `main` 分支（与现在同一个仓库即可，不需要另开仓库）。
2. 仓库 Settings → Pages：Source 选 `Deploy from a branch`，Branch 选 `main` / `/ (root)`。
3. 访问 `https://xiaocaolsj.github.io/TSJ/`，后台为 `https://xiaocaolsj.github.io/TSJ/admin/`。

> 站点全部用相对路径，因此放在 `https://xiaocaolsj.github.io/TSJ/` 这种子目录下也能直接跑，无需改配置。

## 二、后台使用

- 地址：`https://xiaocaolsj.github.io/TSJ/admin/`
- 账号：`TSJ_DSG`
- 密码：`2027fortune!`
- 登录状态保留 12 小时（只存在本机浏览器）。

**Token 已内置：用账号密码登录即可，不需要手动粘贴**

GitHub Pages 是纯静态托管，没有服务器可写文件，所以后台通过 GitHub API 把内容提交回仓库。为了让登录后立刻就能发布，Token 以**密文**形式内置在 `admin/vault.js`：

- 加密方式：PBKDF2-SHA256（240,000 次）派生密钥 + AES-256-GCM，密钥就是后台登录密码。
- 登录成功后浏览器自动解密、自动连接 `XiaoCaoLSJ/TSJ`，右上角状态显示「已连接 … 内置 Token 已自动解锁」即可直接「保存并发布」。
- 解密出的 Token 只放在浏览器 sessionStorage（关掉标签页即消失），不会写入文件。
- 换 Token：后台「连接与发布」→ 把新 Token 填到「GitHub Token」框 → 点「用上方 Token 更新内置配置」→ 会自动加密并提交 `admin/vault.js`。之后所有电脑都用新 Token。
- 若某次登录提示「内置 Token 未解锁」（例如换了密码），点「解锁内置 Token」输入密码，或直接手填 Token 也能发布。

> 安全前提：仓库是公开的，`vault.js` 里只有密文，**密钥强度 = 后台密码强度**。请不要把后台密码发到公开渠道；如需更换密码，告诉我重新生成登录哈希与 vault 即可。

**没有 Token 时**（比如密文对不上）：仍可编辑和「下载 JSON」，手动把 JSON 覆盖到 `data/site.json` 再提交。

## 三、10 秒弹窗与线索（手机号 / 姓名 / 地区）

- 弹窗在页面打开 10 秒后出现，收集 **姓名、手机 / WhatsApp、国家地区**（下拉含 209 个国家/地区 + 国际区号，可选择「Other / not listed」）。
- 出现在「10 秒弹窗」里可调：是否启用、延迟秒数（默认 10）、显示频率（每个会话一次 / 每 7 天一次 / 每次访问）。
- 同一访客提交过线索后不再弹窗；也可随时点击页头 / 手机底栏的按钮主动打开。
- 页面底部还有完整询盘表单（姓名、电话、邮箱、国家、城市、产品类别、需求描述），提交走同一通道。

**线索发到哪个邮箱**：后台「邮件 / 线索接收」→「接收线索的邮箱」，默认 `lsjxiaocao@163.com`。

### 邮件通道（默认 FormSubmit，免注册）

官网没有后端，提交时由浏览器直接调用邮件服务：

1. 默认方式 **FormSubmit**，只需要一个收件邮箱，无需注册。
2. **首次必须激活**：向邮箱地址发出第一封提交后，FormSubmit 会往 `lsjxiaocao@163.com` 发一封激活邮件（可能在垃圾箱），点其中的 `Activate Form` 链接即激活，之后所有线索都会正常投递。
   - 本次开发已在本地试投一次，激活邮件应该已经在收件箱/垃圾箱里。
3. 后台「邮件 / 线索接收」页底部有「发送测试线索」按钮，可随时验证是否真的能收到。

也可以换成其它通道（同一个下拉框切换，填好参数即可，无需改代码）：

| 发送方式 | 需要填写 |
| --- | --- |
| FormSubmit | 接收邮箱（默认，免注册） |
| EmailJS | Service ID、Template ID、Public Key |
| Web3Forms | Access Key |
| 自定义 Webhook | 一个接收 POST JSON 的地址（Zapier / Make / 自建接口等） |
| 关闭 | 不发送（不建议） |

万一发送失败（比如邮件服务暂时不可用），访客会看到提示，并给出带上他已填信息的 WhatsApp / 邮件直达按钮，线索不会静默丢失。

## 四、后台能改什么

按左侧菜单逐项，全部字段自动生成表单，改完点「保存并发布」：

- **站点信息 (SEO)**：浏览器标题、描述
- **品牌标识 / 联系方式**：Logo 字母、品牌名、邮箱、电话、WhatsApp、地址、服务时间
- **邮件 / 线索接收**：收件邮箱、发送方式、各类提示语，含测试发送
- **10 秒弹窗**：开关、延迟、频率、文案、配图
- **首屏轮播**：3 屏图文与按钮（可增删、排序）
- **数据统计**：16+ 年、32,000 m²、120+ 国家、20–40% 等数字
- **板材质量**：6 张卖点卡 + 8 行规格表 + 认证标签 + 配图
- **做工细节**：4 个精度数据 + 5 条工艺说明 + 配图
- **价格优势**：对比表格（项目 / 零售价 / 我们的价格 / 节省）、4 条定价说明、免责说明
- **系列展示 / 产品分类 / 案例展示 / 我们的优势 / 服务流程 / 行动号召 / 联系板块 / 页脚**：卡片、图片、文案
- **高级（JSON）**：直接编辑整份配置

图片字段支持两种方式：填图片地址（外链或站内相对路径如 `assets/img/xxx.jpg`），或点「上传」把本地图片传到仓库 `assets/uploads/` 并自动回填地址。

## 六、安全边界说明（请知悉）

- 后台登录是前端校验（静态站点无法做服务端鉴权），能挡住普通访客，但懂技术的人可以看到后台界面。
- 真正的安全边界是 GitHub Token：没有 Token 谁也改不了仓库内容。本项目的 Token 以密码派生的密文存放（`admin/vault.js`），只有知道后台密码的人能解出，因此**请务必使用足够强的后台密码**，并且只给 Token 授予本仓库的 `Contents: Read and write` 权限、设置 90 天有效期，把风险限制在最小范围。
- 建议把 Token 有效期设为 90 天，到期后在 GitHub 重新生成并更新一次。
- 若需要更严格的后台权限，就得引入一个真实后端（如 Cloudflare Access + Worker、Supabase Auth），可以再做。
